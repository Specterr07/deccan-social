# Instructions for AI coding agents

This project's working instructions live in `CLAUDE.md` — read it first, whatever agent you are (Codex, Antigravity, Gemini, Cursor, Claude Code).

Short version:

1. Read `docs/STATUS.md` to learn where the last session stopped.
2. Pick the next task from `docs/TASKS.md` and follow `docs/SDLC.md`.
3. Before ending, update `docs/STATUS.md` and `docs/TASKS.md`, then commit.

The handoff lives in those files, not in your chat history.
